# 📄 РЕГЛАМЕНТ МИНИ-ТУРНИРА «Зона Хвата НИКИТА ЮРКОВЕЦ»

## 1. Общие положения
*   **Место проведения:** «Зона Хват».
*   **Специальный гость:** известный атлет **Никита Юрковец**.
*   **Общее время:** 2 часа.
*   **Участники:** 20 сильнейших атлетов, прошедших отбор.

## 2. Отбор участников
*   **Этап:** динамометр **ГМ 150 v10**.
*   **Условие:** выдавить **не менее 90 кг**.
*   Прошедшие отбор подходят к стойке регистрации и заполняют бланк участника.
*   Набирается **20 человек**. Если желающих больше — приоритет у показавших лучший результат.

## 3. Основные упражнения

### Упражнение 1: Эспандеры FitFilip (6 шт.)
*   **Нагрузка:** 22, 32, 42, 50, 62, 85 кг.
*   Каждый участник пробует закрыть эспандеры от лёгкого к тяжёлому.
*   **В финал выходят** те, кто закрыл **4-й номер (50 кг)**.
*   Если таких меньше 5 человек — в финал выходят те, кто закрыл **3-й номер (42 кг)**.

### Упражнение 2: Удержание блоба (финал)
*   **Вес блоба:** 15 кг.
*   Каждый финалист держит блоб **одной рукой**.
*   Побеждает тот, кто удержал **дольше всех**.
*   Награждаются **3 призовых места**.

## 4. Программа мероприятия (2 часа)
| Время | Этап |
| :--- | :--- |
| 00:00–00:20 | Отбор на динамометре и регистрация |
| 00:20–00:30 | Приветствие, показательное выступление Никиты Юрковца |
| 00:30–01:00 | Упражнение 1 (эспандеры) |
| 01:00–01:30 | Упражнение 2 (удержание блоба) |
| 01:30–01:50 | Подведение итогов, награждение, фотосессия |
| 01:50–02:00 | Резерв времени |

## 6. Награждение
*   Победители получают призы за **1-е, 2-е и 3-е места**.
*   Специальный приз от Никиты Юрковца — за лучший результат / волю к победе.

## 7. Безопасность
*   Все участники — в спортивной форме, проходят инструктаж.
*   Организаторы обеспечивают страховку (при необходимости).
