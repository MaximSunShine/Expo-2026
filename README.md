# ?? РЕГЛАМЕНТ МИНИ-ТУРНИРА ПО ХВАТУ «НИКИТА ЮРКОВЕЦ»

## 1. Общие положения
*   **Место проведения:** Стенд «Силы Хвата».
*   **Специальный гость:** Никита Юрковец.
*   **Общее время:** 2 часа.
*   **Участники:** 20 зрителей, проявивших желание участвовать в конкурсе.

## 2. Регистрация участников
*   За **15–20 минут** до указанного в регламенте времени проведения мини-турнира открывается регистрация.
*   Участникам необходимо подойти на Стенд «Силы Хвата» и зарегистрироваться для участия в мини-турнире.

## 3. Основные упражнения

### Упражнение 1: ГМ-150 v10
*   Побеждает участник, который покажет **лучший результат (кг)**.
*   Каждому участнику даётся **по 2 попытки**.

### Упражнение 2: Эспандеры FITFILIP (FF 1, FF 2, FF 3, FF 4, FF 5, FF 6)
*   Побеждает участник, который закроет **самый тяжёлый эспандер**.

### Упражнение 3: Подъём блоба 15 кг
*   Участнику необходимо поднять с пола блоб весом **15 кг** и выпрямиться с ним.
*   Побеждает тот, кто сделает **большее количество повторений за 45 секунд**.

## 4. Система начисления баллов
*   Победитель в мини-турнире выявляется по **наибольшему количеству баллов**.
*   Баллы начисляются в каждом упражнении исходя из занятого места:
    *   **1 место — 20 баллов**
    *   **2 место — 19 баллов**
    *   **3 место — 18 баллов**
    *   и так далее.

## 5. Награждение
*   **Пять первых мест** награждаются призами от организаторов и партнёров Никиты (**FITFILIP**).

## 6. Программа мероприятия (2 часа)
| Время | Этап |
| :--- | :--- |
| 00:00–00:20 | Регистрация участников на Стенде «Силы Хвата» |
| 00:20–00:30 | Приветствие, показательное выступление Никиты Юрковца |
| 00:30–01:00 | Упражнение 1 (ГМ-150 v10) |
| 01:00–01:30 | Упражнение 2 (эспандеры FITFILIP) |
| 01:30–01:50 | Упражнение 3 (подъём блоба) |
| 01:50–02:00 | Подведение итогов, награждение, фотосессия |
